## Review Focus
- A source description is shared data: only recipe-created ZZSPIKE descriptions/collections may be updated or deleted; never a pre-existing one. Deleting a description that persons/relationships still reference must be handled in teardown order.
- `deleteSourceDescriptionsFromCollections` and `updateSourceDescriptionsToCollection` change membership: assert membership of exactly the intended descriptions (siblings unchanged), not just 2xx.
- Reads that beta answers for any uid (`readUserSourceDescriptions` ignored the uid in P2) stay deferred unless a content-differing control is possible.
- Known live quirks: HEAD source description has no validators; person source-references endpoint 404s right after attach (poll); empty 204 controls need `control_may_be_empty` with a reason.
